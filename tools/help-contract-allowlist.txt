# Help contract allowlist — surfaces that may ship without help content.

# Enforced by tools/check_help_contract.py. Format, one entry per line:
#
#     <route|widget|logic-block|skin>:<name>  # why this surface has no help
#
# The reason is mandatory: the point of this list is that every gap stays
# visible, versioned, and justified instead of silently existing. Keep it
# tight — an entry is a promise that the surface genuinely needs no help,
# or a tracked debt, not a way around writing documentation.
#
# The list is checked back against reality. An entry for a surface that no
# longer exists, or for one that meanwhile *is* documented, fails the gate
# too, so removing content or writing it always forces the list to be
# updated with it.
