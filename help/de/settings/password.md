# Passwort ändern

Das eigene Passwort kann im Admin-GUI unter **Einstellungen → Passwort** geändert werden.

## Eigenes Passwort ändern {#settings-password}

**Aktuelles Passwort** — muss korrekt eingegeben werden, um die Änderung zu bestätigen. Bei
falscher Eingabe wird die Änderung abgelehnt, auch wenn man selbst angemeldet ist.

**Neues Passwort** und **Neues Passwort wiederholen** — müssen exakt übereinstimmen, sonst
erscheint die Meldung „Passwörter stimmen nicht überein" und nichts wird gespeichert. Es gibt
keine zusätzliche Komplexitätsanforderung (Länge, Sonderzeichen o. Ä.) — jedes nicht-leere
Passwort wird akzeptiert, solange beide Felder übereinstimmen.

Nach erfolgreicher Änderung werden alle drei Felder geleert und eine
Bestätigungsmeldung angezeigt.

**Demo-Modus:** Ist man als Demo-Benutzer angemeldet, ist dieser Bereich schreibgeschützt
und lässt sich nicht bearbeiten.
