# Links

Der Links-Tab findest du im Admin-GUI unter **Einstellungen → Links**.

## Eigene Links {#settings-links}

Verwaltet eigene Links, die in der Seitennavigation erscheinen — sichtbar für **alle**
Benutzer, nicht nur für Administratoren. Typischer Einsatzzweck: Verweise auf externe
Werkzeuge wie ein Grafana-Dashboard.

Jeder Link besteht aus Bezeichnung, URL, optionalem Icon und einer Reihenfolge-Nummer, die die
Position in der Navigation bestimmt. „In neuem Tab öffnen" lässt den Link in einem separaten
Browser-Tab statt in der aktuellen Ansicht öffnen.
