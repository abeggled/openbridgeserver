# Change Password

Your own password can be changed in the Admin GUI under **Settings → Password**.

## Change your own password {#settings-password}

**Current password** — must be entered correctly to confirm the change. If it's wrong, the
change is rejected even though you're already logged in.

**New password** and **Repeat new password** — must match exactly, otherwise the "Passwords
do not match" message appears and nothing is saved. There is no additional complexity
requirement (length, special characters, etc.) — any non-empty password is accepted as long
as both fields match.

After a successful change, all three fields are cleared and a confirmation message is shown.

**Demo mode:** If you're logged in as the demo user, this section is read-only and cannot be
edited.
