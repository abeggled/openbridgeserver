# Links

The Links tab lives in the Admin GUI under **Settings → Links**.

## Custom links {#settings-links}

Manages custom links that appear in the sidebar navigation — visible to **all** users, not
just administrators. Typical use case: linking to external tools such as a Grafana dashboard.

Each link has a label, a URL, an optional icon, and a sort-order number that determines its
position in the navigation. "Open in new tab" makes the link open in a separate browser tab
instead of the current view.
